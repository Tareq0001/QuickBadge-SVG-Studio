# QuickBadge SVG Studio 🛡️✨

> An interactive, client-side vector SVG badge generator for GitHub repositories, documentation, and web profiles.

Developed by **Tareq Aboushi** ([@Tareq0001](https://github.com/Tareq0001)).

---

## 🌟 Features
- **Live Vector Rendering:** Instant updates as you tweak text, colors, icons, and dimensions.
- **Multiple Badge Styles:** Flat, Flat-Square, Plastic, and Gradient pill layouts.
- **Icon Integration:** Bundled SVG icons (GitHub, Star, Shield, Flame, Heart, Verified Check, Lightning, Python, JS).
- **Multi-Format Export:** Export as pure SVG file, Markdown embed snippet, or raw HTML.
- **Built-in Presets:** Quick one-click badges (Build Passing, Version, License MIT, Stars, Coverage 98%).
- **Bilingual Interface:** Instant Arabic / English localization with RTL support.
- **Offline & Zero Dependencies:** 100% vanilla JavaScript, HTML5, and CSS3.
